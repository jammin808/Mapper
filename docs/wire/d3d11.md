# wp2-d3d11 on the wire

The D3D11 present path, Spout and per-output latency, continuing wp2-output (`docs/wire/output.md`). The design is
`docs/OUTPUT.md` and, for Spout, `docs/VIDEO.md`.

## Verbs

| Verb | Syntax | Words | Risk | Changes the show |
|---|---|---|---|---|
| `PRESENT PATH` | `PRESENT PATH AUTO\|DXGI\|GL` | Where outputs present from the render host's next start: AUTO is OpenGL this round; DXGI (flip model on Windows) is experimental until proven on the machine (kept on the node) | high | yes |

- **Answers**: `{"asked","was","applies":"next start","experimental","fuseCleared","words"}`. AUTO's words say AUTO is OpenGL on
  every platform this round.
- **Refused**: a no-op ("PRESENT PATH is already GL (from the render host's next start)"); `DXGI` off Windows ("the DXGI path is
  Windows only (this node runs Linux): outputs present through OpenGL"); a node with no home ("this node keeps no settings …"); any
  other word. Asking `DXGI` again while a fuse is blown clears the fuse.
- **`PRESENT RESET`** (wp2-output's row): with no output named, or `ALL`, it also clears a blown fuse
  ("the present fuse is cleared: the DXGI path is tried again at the render host's next start").
- **Spout lines** are videoio's rows (`SEND ADD SPOUT …`, `INPUT ADD spout:Name`, `INPUT DISCOVER SPOUT`, `VIDEOIO SET SPOUT …`);
  this package's provider answers them. Off Windows each is refused "Spout is Windows only".
- **Output latency** is the output's `latencyMs` field (`SET <output> latencyMs <0–500>`); a value that would make an output wait more
  than six frames for the slowest display is refused with the words.

## STATE

`machine.present` (after wp2-output's keys):

| Key | Type | Meaning |
|---|---|---|
| `asked` | string | `auto`, `gl` or `dxgi`: what the node's next render host start asks (as kept on the node) |
| `kept` | bool | the node keeps present settings (it has a home) |
| `fuse.state` | string | `clear`, `armed` (this DXGI start waits for its outputs' first settled frames) or `blown` (OpenGL until `PRESENT RESET` or `PRESENT PATH DXGI`) |
| `fuse.attempt` | number | DXGI starts in a row that armed it |
| `fuse.at` | number | unix ms of the last |
| `airLatencyMs` | number | the node's air latency: the largest enabled output's input lag, or the group's when larger |
| `latencyWords` | string | why an output's delay was capped ("" otherwise) |

`machine.present.path` is `dxgi` on the flip path, `api` `d3d11`, `adapter` "Direct3D 11 + ANGLE · <adapter>", `context`
`angle-d3d11`, `experimental` true. `outputs[].present.path` is `dxgi-flip`; `delayFrames` and `latencyResidualMs` carry the latency
plan. Spout's STATE is videoio's (`videoio.spout`, `videoio.sends[]`, `videoio.inputs[]`).

## Preflight, cards

- **Preflight** row `outputs.present-path`: amber "fuse blown" with fix `PRESENT RESET`; amber with the words when the path is not the
  one asked; green otherwise.
- **Cards** (`tests/fixtures/state/output.cards.json`): the Presentation card shows `delayFrames`; the Present path card shows the path,
  `asked`, `fuse.state`, the adapter, `airLatencyMs`, with actions `PRESENT RESET` and `PRESENT PATH GL`.

## Seams for other packages

- `IPresentBackend.SetGroupAirLatency(ms)`: a sync group's slowest node raises this node's air latency (0 lets it go). It is the seam
  sync's group-latency row writes through.
- `IGpuPlatform.Share` is `GpuApi.D3D11` on the flip path (the device pointer and its LUID).
