# L11 — The installed node: M9, auto-logon, Shell Launcher, an upgrade refused while armed

*Package: wp3-installer (`docs/round3/PLAN.md` §7). **Not run: no lab: the owner's answer 5** (§9 decision 11). The script and its
pass mark stand as written, for a lab booked later. What CI proves instead is in `docs/INSTALL.md`, "What is proven, and where".*

## The machine

A clean Windows 11 IoT Enterprise LTSC 2024 install (build 26100) on a show machine with a discrete GPU and one display connected,
on a network set to Private; an administrator account to install with; two numbered unsigned installers of one line (`A` and a later
`B`) with their `SHA256SUMS`. Record the machine, the GPU, its driver and both builds:

```powershell
Get-ComputerInfo -Property OsName, OsVersion, OsBuildNumber
Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion
```

## Steps

1. Make the show account, a standard user (elevated PowerShell): `net user show <password> /add`. Check that
   `net localgroup Administrators` does not list it.
2. Auto-logon with Sysinternals Autologon (`Autologon64.exe`): user `show`, domain the computer's name, its password. Check
   `reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v AutoAdminLogon` reads `1` and that
   `reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword` finds no value.
3. Check installer `A` against its sums: `Get-FileHash .\PlayMap-<A>-win-x64-unsigned.exe -Algorithm SHA256` matches its line in
   `SHA256SUMS`.
4. Install `A`, elevated:
   `.\PlayMap-<A>-win-x64-unsigned.exe /VERYSILENT /SUPPRESSMSGBOXES /SHOWUSER=<COMPUTER>\show /LOG=C:\lab\L11-install.log`, then
   `$LASTEXITCODE` reads `0`.
5. `& "C:\Program Files\PlayMap\Supervisor\PlayMap.Supervisor.exe" status`: record the answer.
6. Cold boot: `shutdown /s /t 0`, power on, let auto-logon sign `show` in. Then, elevated:
   - `query session` — the show account's session id;
   - `Get-CimInstance Win32_Process -Filter "Name='PlayMap.exe'" | ForEach-Object { [pscustomobject]@{ Pid = $_.ProcessId; Session = $_.SessionId; User = $_.GetOwner().User; Line = $_.CommandLine } }`
     — the engine (`PlayMap.exe engine --supervised`) runs as `show` in that session, never in session 0;
   - `PlayMap.Supervisor.exe status` — `running`, with that pid.
7. Shell Launcher: `Dism /online /Enable-Feature /all /FeatureName:Client-EmbeddedShellLauncher`; make the show account's shell
   the engine, as `docs/INSTALL.md` says (Shell Launcher's `WESL_UserSetting.SetCustomShell` with the show account's SID and
   `"C:\Program Files\PlayMap\PlayMap.exe" engine --supervised`, then `SetEnabled($true)`); reboot. Record which process started
   the running engine (`ParentProcessId` of the query in step 6), that exactly one engine runs, and what `status` names.
8. An hour's show on the display: a looping clip on one output. Every 250 ms read `GET http://127.0.0.1:9940/health` and keep its
   time, `outputs[].shownFrames` and `gpu.phase`:
   ```powershell
   $log = 'C:\lab\L11-health.csv'; 'at,shown,phase' | Set-Content $log
   $end = (Get-Date).AddHours(1)
   while ((Get-Date) -lt $end) {
     $h = Invoke-RestMethod http://127.0.0.1:9940/health
     "$([DateTimeOffset]::UtcNow.ToUnixTimeMilliseconds()),$($h.outputs[0].shownFrames),$($h.gpu.phase)" | Add-Content $log
     Start-Sleep -Milliseconds 250
   }
   ```
   The longest time `shown` stood still while `phase` was `running` is the longest shown-frame gap outside a rebuild.
9. Arm the show: `Invoke-RestMethod -Method Post -Uri http://127.0.0.1:9940/api/cmd -Body 'SHOW ARM lab'`.
10. Run installer `B` as in step 4 (its own log, `C:\lab\L11-upgrade-armed.log`): `$LASTEXITCODE` is not `0`; the log carries
    `the show is armed on this node since <HH:mm> by <who>: disarm first`; `status` names the same engine pid as before;
    `(Get-ItemProperty HKLM:\SOFTWARE\PlayMap).Version` still reads `A`'s version.
11. Disarm (`SHOW DISARM` as in step 9) and run installer `B` again: `$LASTEXITCODE` reads `0`, the version reads `B`'s, and
    `status` reads `running` with a new engine.

## The pass mark (§7)

The supervisor starts the engine in the show user's session after a cold boot; the armed refusal's words; the longest shown-frame
gap outside a rebuild recorded (the supervisor's floor).

## The record

The machine, its GPU and driver, builds `A` and `B`, the answers of steps 5, 6, 7, 10 and 11, the longest gap of step 8 in
milliseconds, and the three logs.
