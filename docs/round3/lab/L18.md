# L18 — The unsigned installer as a person meets it

*Package: wp3-installer (`docs/round3/PLAN.md` §7). **Not run: no lab: the owner's answer 5** (§9 decision 11). The script and its
pass mark stand as written, for a lab booked later. What CI proves instead is in `docs/INSTALL.md`, "What is proven, and where".*

## The machines

Two clean installs, each as its setup leaves it: Windows 11 Home and Windows 11 Pro (25H2 or later), each with a browser (Edge as
installed) and an administrator account. One numbered unsigned installer and its `SHA256SUMS`, published where a browser downloads
them from (the release page). Record each machine's edition and build (`Get-ComputerInfo -Property OsName, OsBuildNumber`) and the
installer's name.

## Steps (on each machine)

1. Read Smart App Control's state:
   `(Get-ItemProperty HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy).VerifiedAndReputablePolicyState` (`0` off, `1` enforcing,
   `2` evaluating). Record it; Windows Security ▸ App & browser control ▸ Smart App Control shows the same.
2. With Smart App Control **enforcing** (a clean install that has finished evaluating; set it on in Windows Security where it may
   be): download the installer through the browser and run it. Record, with a screenshot each: Windows' own block (the installer
   does not start); that no PlayMap process runs (`Get-Process PlayMap*` finds none); and the block in the Code Integrity log:
   ```powershell
   Get-WinEvent -LogName 'Microsoft-Windows-CodeIntegrity/Operational' | Where-Object Id -eq 3077 |
     Select-Object -First 5 TimeCreated, Message
   ```
3. With Smart App Control **evaluating** (a fresh install's state): download and run the installer. Record, with screenshots:
   SmartScreen's "Windows protected your PC" with an unknown publisher, and More info ▸ Run anyway; UAC naming the publisher
   "Unknown"; the installer's Smart App Control warning page ("Smart App Control is evaluating this PC: once it enforces, Windows
   blocks this unsigned build and the node will not start. Turn it off in Windows Security > App & browser control before the
   show."). Cancel at the next page.
4. With Smart App Control **off**: download and run the installer, through SmartScreen and UAC as in step 3, to its end. Its pages
   name no show account (only `/SHOWUSER=` on its command line does, `docs/INSTALL.md`), so this install names none and the supervisor
   starts the engine as whoever is signed in. Record that it completes, then check the
   download against its sums: `Get-FileHash .\PlayMap-<version>-win-x64-unsigned.exe -Algorithm SHA256` matches its line in
   `SHA256SUMS`, and `& "C:\Program Files\PlayMap\Supervisor\PlayMap.Supervisor.exe" status` answers.
5. Compare each screen with `docs/INSTALL.md`, "Unsigned builds": every prompt and block it names is seen, worded as it says.

## The pass mark (§7)

Downloaded through a browser: SmartScreen's "unknown publisher" prompt and More info ▸ Run anyway as `docs/INSTALL.md` shows them;
UAC's "Unknown publisher"; with Smart App Control enforcing, Windows' own block of the installer as `docs/INSTALL.md` shows it,
nothing of PlayMap running, and event 3077 logged; evaluating, the MSI's warning page; off, the install completes and `SHA256SUMS`
matches. (This round the warning page is the Inno Setup installer's: `docs/INSTALL.md`, "What the installer is".)

## The record

Each machine's edition and build, the installer's name, Smart App Control's state at each step, the screenshots, the 3077 events'
times and messages, and any wording that differs from `docs/INSTALL.md`.
