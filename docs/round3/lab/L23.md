# L23 — A Windows 11 Home node (the installer's part)

*Packages: wp3-platform and wp3-installer (`docs/round3/PLAN.md` §7). This script is the installer's part: the local show account,
auto-logon and the supervisor starting the engine after a cold boot. The platform's part — preflight's edition rows and hard rows,
an hour's show with L1's measures beside a Pro machine's, Memory Integrity and the media volume's encryption with their frame times,
the air during a UAC prompt, a projector's power cycle with and without EDID emulation — is wp3-platform's script,
`L23-home-node.md` beside this one. **Not run: no lab: the owner's answer 5** (§9 decision 11).*

## The machine

A clean Windows 11 Home 26H2 install as its setup leaves it: signed in with a Microsoft account, Smart App Control evaluating, device
encryption on, OneDrive folder backup on; a GPU and one display; one numbered unsigned installer and its `SHA256SUMS`. Record the
edition and build (`Get-ComputerInfo -Property OsName, OsBuildNumber`), the GPU and its driver, and the installer's name.

## Steps

1. Smart App Control off for the unsigned build, as `docs/INSTALL.md` says (Windows Security ▸ App & browser control); check
   `(Get-ItemProperty HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy).VerifiedAndReputablePolicyState` reads `0`.
2. Make the local show account with a password, as `docs/INSTALL.md` says for Home (elevated): `net user show <password> /add`;
   `net localgroup Administrators` does not list it.
3. Auto-logon to it with Sysinternals Autologon (`Autologon64.exe`: `show`, the computer's name, its password); check
   `AutoAdminLogon` reads `1` and `DefaultPassword` is absent (L11's step 2).
4. Check the download against its sums and install elevated, as L11's steps 3 and 4 do, with `/SHOWUSER=<COMPUTER>\show`;
   `$LASTEXITCODE` reads `0`.
5. Cold boot (`shutdown /s /t 0`, power on); auto-logon signs `show` in. Elevated: `query session`, the process query of L11's
   step 6 — the engine runs as `show` in its session, never session 0 — and `PlayMap.Supervisor.exe status` reads `running`.
6. Read the install's facts the desk shows: `Invoke-RestMethod http://127.0.0.1:9940/api/state` and its `machine.install` block —
   `installed`, `supervised`, `showUser`, `autoLogon.on` and `autoLogon.user` as steps 2–5 made them, and `edition` naming Home.
