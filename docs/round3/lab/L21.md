# L21 — M13: the first ten minutes

*Package: wp3-installer (`docs/round3/PLAN.md` §7). **Not run: no lab: the owner's answer 5** (§9 decision 11). The script and its
pass mark stand as written, for a lab booked later. Until it runs, ReadyToRun is the default without this record (M13).*

## The machine

The RTX PRO node of `docs/round3/PLAN.md` §7 (its first output on a display at its native mode), with the installer's ReadyToRun
build (§7's "the MSI's ReadyToRun build": an Inno Setup installer this round) installed per machine (L11's steps 1–5), and a show
of the kind it plays: a project with a looping 4K HAP clip and a 4K H.264 clip on its outputs. Intel's PresentMon 2.6.0 (MIT) in `C:\lab\PresentMon`. Record the machine, its GPU and driver, the build and the
project.

## Steps

1. Cold boot and let auto-logon start the engine; then, elevated, hold it so the capture sees its first frames:
   `& "C:\Program Files\PlayMap\Supervisor\PlayMap.Supervisor.exe" stop` (it answers `OK held`).
2. Start the capture of the engine's presents for twenty-one minutes:
   ```powershell
   C:\lab\PresentMon\PresentMon.exe --process_name PlayMap.exe --output_file C:\lab\L21-presents.csv --v1_metrics `
     --timed 1260 --terminate_after_timed
   ```
3. Start the engine (`PlayMap.Supervisor.exe resume`) and start the show as soon as it answers (the desk's GO, or
   `Invoke-RestMethod -Method Post -Uri http://127.0.0.1:9940/api/cmd -Body 'GO'`). The capture's first row is the first present.
4. Beside the capture, every second read `GET http://127.0.0.1:9940/health` and keep `watchdog.renderMs` (the render's p95) with its
   time, as L11's step 8 does.
5. Once the capture ends, compute from its `MsBetweenPresents` the p99.9 frame time of minutes 0–10 and of minutes 10–20, counted
   from the first present:
   ```powershell
   $rows = Import-Csv C:\lab\L21-presents.csv
   $t0 = [double]$rows[0].TimeInSeconds
   function P999($xs) { $s = $xs | Sort-Object; $s[[math]::Ceiling(0.999 * $s.Count) - 1] }
   $first = $rows | Where-Object { [double]$_.TimeInSeconds - $t0 -lt 600 } | ForEach-Object { [double]$_.MsBetweenPresents }
   $next = $rows | Where-Object { $d = [double]$_.TimeInSeconds - $t0; $d -ge 600 -and $d -lt 1200 } | ForEach-Object { [double]$_.MsBetweenPresents }
   "minutes 0-10 p99.9 $(P999 $first) ms; minutes 10-20 p99.9 $(P999 $next) ms"
   ```

## The pass mark (§7)

p99.9 frame time over a show's first ten minutes recorded against minutes 10–20.

## The record

The machine, GPU, driver, build and project; both p99.9 values; the capture and the health samples. The record decides M13: whether
